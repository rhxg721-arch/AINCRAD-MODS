# Aincrad Mods — UI Demo
Open this folder in Android Studio (JDK 17, Android SDK 35), allow Gradle sync, then Run.
Tap Enable Floating Panel and grant Display over other apps permission.
This project is a UI demo only. Switches/sliders do not modify games or access game memory.
No APK is included, and an actual Gradle/Android SDK build has not been run in this environment.
